# 料金を決める処理と、表示する文章を分ける

Java 17以上。外部ライブラリ、Spring、データベースは不要です。

## 動かす

```sh
mkdir -p out
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

```text
整理前：請求額：6500円
整理後：請求額：6500円
見積額：6500円
小計：6000円／送料：500円
```

## ファイルの役割

- `BeforeReceipt`：料金の計算と請求額の文字列作成を同じメソッドで行う。現在の仕様では正しく動く。
- `OrderPrice`：単価・数量のチェック、小計・送料・合計の計算を行う。
- `ReceiptText`：決まった料金を「請求額：…円」という文章にする。
- `Main`：整理前後の同じ表示と、料金だけを見積表示に使う例。

## 仕様

- 単価は0円以上、数量は1個以上の整数。
- 商品は1種類。小計は単価×数量。
- 小計10,000円以上なら送料0円。それ未満は500円。
- 税・割引・地域別送料・保存処理は扱わない。
- intで表現できない計算はArithmeticExceptionになる。
- 現在の料金を計算する例。過去の請求額の再計算や、条件の違う送料を同時に扱う例ではない。

## 変更課題

1. 送料無料を8,000円以上に変更するなら、`OrderPrice.FREE_SHIPPING_FROM`を変える。呼び出す側へ同じ条件を書かない。
2. 表示を「お支払額：…円」に変えるなら、`ReceiptText.format`だけを変える。
3. 7,999円、8,000円、8,001円の入力で送料と合計を確認する。

整理後もBeforeReceiptは比較用として元の10,000円ルールを残しています。ルールを変更する練習をした後、整理前後の出力が同じだと期待しないでください。

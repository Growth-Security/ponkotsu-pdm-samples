# Javaのテスト入門：仕様からケースを選ぶ

学習用に独自作成したサンプルです。書籍収録コードの転載ではありません。

## 実行環境

- JDK 17以上
- Maven 3.9系
- JUnit Jupiter 5.12.2（pom.xmlで固定。最新版であるとの主張ではありません）
- 初回はMavenの依存ライブラリ取得にネットワーク接続が必要

このフォルダを開き、次を実行します。

```sh
mvn test
```

9件が成功します。Spring、DB、Mockito、外部APIは使用しません。

## 送料の仕様

- 小計は整数の円。0円から1,000,000円を受け付ける。
- 小計が10,000円以上なら送料0円。それ以外は送料500円。
- 範囲外はIllegalArgumentException。
- 小計0円を受け付けるのは、この練習の仕様。すべての業務に当てはまるルールではない。

## ケースの選び方

送料が切り替わる直前・境界・直後として9,999 / 10,000 / 10,001円を選びます。
入力可能範囲の下限側は-1 / 0 / 1円、上限側は999,999 / 1,000,000 / 1,000,001円です。
期待値は上の仕様から決めます。本体コードの条件式をテストへコピーしてはいけません。

## 失敗を確認する

ShippingFee.javaの `subtotal >= 10_000` を一時的に `subtotal > 10_000` にすると、10,000円のケースが失敗します。
実行結果には expected: <0> but was: <500> と表示されます。期待値を500へ変更せず、本体を元に戻してください。
「テストを通すため」ではなく、「10,000円以上は無料」という仕様に合わせます。

## 仕様を変更する練習

仕様が「8,000円以上は無料」に変わったときは、先に新しい境界の7,999 / 8,000 / 8,001円と期待値を追加します。
変更前の本体で8,000円と8,001円のケースが失敗することを確認し、本体のしきい値を8,000円へ変更してから全件実行します。
以前の9,999円の期待値は新仕様では0円です。既存ケースの期待値も仕様と照合して更新します。
入力の下限・上限という別の約束を確認するケースは残します。

## ファイル

- src/main/java/ShippingFee.java:送料を求める本体
- src/test/java/ShippingFeeTest.java:入力と期待値を独立に記述した9ケース
- pom.xml:実行に必要な依存関係

この例で確認するのは入力・戻り値・例外です。将来Webアプリに組み込んだ場合の画面連携や保存までは確認しません。
